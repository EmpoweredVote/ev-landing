A 122-megabyte answer, an audit that came back, and a season nobody closed the door on

The oldest unpaid item on this page has been paid, and the answer was not the one it was waiting for. For five editions this page has said that four cycles of Treasury performance work were unproven because nobody had timed the real page, and that the database doubling twice made the measurement more urgent rather than less. It was measured this week, and the doubling had already broken it. Essentials asked the platform API for its list of governments with budget data, unnarrowed. That request returned one row per budget, and budgets doubled in October — 296,172 of the 583,189 rows in that table were created this month. The response had grown to 122 MB and about 47 seconds, past the API’s 30-second limit, so in production it did not return at all: the call failed, fell back to an empty list, and Essentials quietly rendered no budget link. Each attempt also held one of the API’s ten database connections for the full 30 seconds. It was not a slow page. It was a broken one, and it failed silently, which is why four cycles of profiling never found it.

It is fixed, deployed, and checked from outside. The app now asks for a lean index shape, and the unnarrowed request is refused outright instead of timing out. Measured against the live API while writing this page: the old shape returns a refusal in 0.24 seconds, and the shape the app now uses returns 2.0 MB in 1.0 second. A faster call is still not a faster page — that remains untimed, and the claim here is narrower and better evidenced than the one this page kept asking for: a request that was failing now succeeds.

The stance audit came back, and it takes a different shape than this page has described. Positions a voter is served fell 32,072 to 31,842 while stored rows rose to 38,507 — the divergence this page named in October. But the mechanism has changed. This page has described a withdrawal as an insert: a blank written over an older answer. This cycle 44 withdrawals were inserts and 240 were rewrites of rows that already existed. Read by creation date — the way this page has read it until now — the audit would have looked like 44 rows of work instead of 284. A measurement that only watches for new rows cannot see a campaign that edits old ones.

And asking which season those positions come from gives the most uncomfortable number on this page. Of the 31,842 positions a voter is served, 28,262 — 88.8% — come from Season 1, which closed on September 4. The open season supplies 3,506 and the Season 3 draft 74. Nothing is wrong with the data and nothing is being hidden; a Season 1 answer is served because no newer one has replaced it. But the ladder the Compass asks today accounts for 11% of what a voter actually reads, and this page has never said so.

The provenance debt, three days on

A provenance grade is the sentence that says where a budget figure came from and who, if anyone, checked it. Ours run from an audited statement prepared under government accounting standards, through a compilation drawn from audited figures, down to a government’s own unaudited filing — which is what a small town’s budget usually is, and is an honest answer. “Unknown” is not a grade on that scale. It means nobody recorded the answer.

The last edition named this the larger of its two debts and said this page would report it the week it was paid. It has not been paid, and this is that report. Not one of the 245,604 moved. There is no excuse to offer and no progress to describe: the three days went to the stance audit, to campaign-finance transparency in Essentials, and to the broken request. Those were worth doing and this was not done. Saying so plainly is the only thing this page can usefully do about it, and repeating the figure unchanged is how a reader can tell a debt from an intention.

Follow the money

The third leg, alongside votes and stances. The platform holds 29.2 million individual campaign-finance contributions totaling $8.6 billion, covering 2,268 federal politicians and candidates across 24 election cycles (1980 to 2026). Every record traces to its original filing, and superseded lines from amended filings are retired individually rather than counted twice. This cycle the work moved from counting the money to labelling it. A reader can now filter a politician’s contributions to one top donor and open that donor’s own transactions; Los Angeles public matching funds are shown on their own line beside total raised rather than folded into it; loans and one filing schedule are no longer counted as money raised; and the summary footer, the confidence tooltip and the source description now name the actual source instead of implying it is federal. Three of those five are corrections to claims the app was making about its own data, which is the same standard this page holds itself to.

The Road Ahead

How much further we have to go, honestly.

Now to Nov

Election readiness

Grade the budgets. It was the last edition’s first debt, it is this one’s, and with under two weeks to the election 245,604 ungraded budgets are already in front of readers. Sources and method. App statuses from git history across all repositories, read from each repository’s published branch rather than from a working copy, with an explicit time of day on every window; this cycle covers the three days since the last edition was committed, which is the shortest window this page has reported on. One repository, Fallacy Finders, has no remote, so it is the single exception and is read locally. Database counts queried live on October 23, 2026. Reach figures are from PostHog — the 30 and 90 days ending October 23, 2026, internal and test traffic excluded, each app counted once across every hostname that serves it; the substitution used to exclude that traffic was controlled against the native filter on four rows and agreed exactly. “Visitors” and the per-app action counts are both unique people over the same window, so a rate between them is fair but is not a strict funnel. The headline stance figure counts positions, not stored rows — the newest season’s answer per person and topic, where that answer is not a withdrawal — and is not comparable with editions before October 10; the coverage table reconciles against the stored count, which is printed beside it. The season each served position comes from was derived the same way, by taking the highest season number per person and topic, and the 88.8% is that count over the served total. The withdrawal split between inserted and rewritten rows compares each row’s creation time with its last update time, which is why this cycle’s audit reads 284 rows of work rather than the 44 a creation-date reading would show. The two Treasury request timings were measured from outside, against the live public API while this page was written, not taken from a commit message. Provenance grades are read from the budget rows themselves; 287,006 older budgets carry no creation timestamp, so the unknown pile is reported as a standing total rather than a time series. A politician’s state resolves through a fixed order of jurisdiction links, and federal seats are identified structurally, which is why they form one row.
